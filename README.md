# colonel1223-site

Personal site. TypeScript, Next.js, Tailwind CSS.

## Pages

- `/` — Home
- `/research` — Research overview
- `/projects` — Project index
- `/publications` — Papers and publications
- `/cv` — Curriculum vitae
- `/demos` — Interactive demonstrations
- `/writing` — Essays and notes
- `/vision` — Long-term research vision
- `/philosophy` — Philosophical framework
- `/contact` — Contact info

## Run locally

```bash
npm install && npm run dev
```

## Stack

TypeScript, Next.js (App Router), Tailwind CSS, GitHub Pages
